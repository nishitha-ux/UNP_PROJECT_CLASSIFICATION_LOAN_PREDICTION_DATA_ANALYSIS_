# UNP_PROJECT_CLASSIFICATION_LOAN_PREDICTION_DATA_ANALYSIS_
I did this project in collaboration with UNP, this project uses Machine Learning to predict loan repayment outcomes based on customer, financial, loan, and credit-related information. The dataset contains 20,000 records and 22 variables. The data was cleaned and preprocessed using Python, including outlier analysis, categorical variable encoding. Logistic Regression, Decision Tree, and Random Forest classification models were developed and evaluated using accuracy, precision, recall, F1-score, and confusion matrices across different train-test split ratios. Among the models tested, the Decision Tree achieved the best overall performance, with an accuracy of approximately 89.6%, demonstrating how machine learning can support data-driven lending and credit risk decisions.
