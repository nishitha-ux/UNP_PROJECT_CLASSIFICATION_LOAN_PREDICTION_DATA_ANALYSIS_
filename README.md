# UNP_PROJECT_CLASSIFICATION_LOAN_PREDICTION_DATA_ANALYSIS_
I did this project in collaboration with UNP, where I created a Loan Repayment Prediction and Analysis project using Classification Machine Learning algorithms. The project analyzes customer, financial, loan, and credit-related information to understand repayment patterns and predict whether a loan will be repaid or not. After data preprocessing and Exploratory Data Analysis, I implemented Logistic Regression, Decision Tree, and Random Forest models. The models were evaluated using different train-test splits and classification performance metrics. This project demonstrates how machine learning can support loan prediction and credit-risk management.
